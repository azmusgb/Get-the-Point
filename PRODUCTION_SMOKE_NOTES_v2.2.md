# Production smoke notes — v2.2

The live production smoke is intentionally read-only. Physical iPhone Safari, installed PWA lifecycle, real DRAW input, VoiceOver, real background/timer behavior, and human Decision Tension remain outside automated proof and are tracked in GitHub Issue #11.
